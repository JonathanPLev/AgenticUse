# CDP Site Crawler - Organized Structure

## Essential Files (Top Level)
- `cdp_site_crawler_fixed.cjs` - Main crawler script
- `function_tracker.js` - Comprehensive function tracking system
- `enhanced_instrumentation_optimized.js` - Page instrumentation
- `bot_mitigation_final_fix.js` - Bot detection mitigation
- `consent_handler_fixed.js` - Cookie consent handling
- `enhanced_input_interaction.js` - Form interaction system
- `generic_detection_fixed.js` - AI tool detection
- `helpers.js` - Core utility functions
- `static_data_structs.cjs` - Static data and configurations

## Organized Folders

### `old_files/`
Deprecated and unused files
- Contains deprecated versions of core files
- Previous implementations and unused code

### `test_files/`
Test scripts and validation files
- All test scripts and validation files
- Test results and analysis

### `utils/`
Utility and helper files
- Helper scripts and utilities
- Configuration files

### `documentation/`
Documentation and analysis files
- Markdown files and analysis reports
- Documentation and comments

### `profiles_and_temp/`
Browser profiles and temporary directories
- Browser profiles and temporary directories
- Test profiles and user data folders

## Usage
Run the main crawler with:
```bash
node cdp_site_crawler_fixed.cjs
```
